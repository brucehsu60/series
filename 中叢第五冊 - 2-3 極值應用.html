（一）平面與立體幾何的極值問題（中叢 p.2-34 ～ p.2-35 第 1 題 ～ 第 4 題）
第 1 題：正方形鐵片四角截去小正方形摺成長方體的最大容積中叢 p. 2-34
1. 將邊長為 $6$ 公寸的正方形鐵片，四個角各截去一個面積相等的正方形，然後再將各邊摺起來，做成一個無蓋的長方體容器。設截去的正方形邊長為 $x$ 公寸，長方體的容積為 $f(x)$ 立方公寸（鐵片厚度不計）：
(1) 求 $x$ 的範圍
(2) 寫出函數 $f(x)$
(3) 當 $x$ 為多少時，長方體的容積 $f(x)$ 會最大？
（兩軸單位長 1:1 精準比例）
📘 【正規詳解】
(1) 求 $x$ 的範圍：
折起後的無蓋長方體底面為正方形，其邊長為 $6 - 2x$ 公寸，高為 $x$ 公寸。因為幾何邊長皆須大於 $0$：
\[ \begin{cases} x \gt 0 \\ 6 - 2x \gt 0 \end{cases} \implies \color{#dc2626}{0 \lt x \lt 3} \] (2) 寫出容積函數 $f(x)$：
長方體容積 $=$ 底面積 $\times$ 高，展開整理得：
\[ f(x) = (6 - 2x)^2 \cdot x = (36 - 24x + 4x^2)x = \color{#2563eb}{4x^3 - 24x^2 + 36x} \] (3) 利用導數求容積最大值發生位置：
求一階導數並因式分解：
\[ f'(x) = 12x^2 - 48x + 36 = 12(x^2 - 4x + 3) = \color{#2563eb}{12(x - 1)(x - 3)} \] 令 $f'(x) = 0$，得 $x = 1$ 或 $x = 3$（其中 $x = 3$ 不在開區間 $0 \lt x \lt 3$ 內）。
如右圖容積函數曲線所示：當 $0 \lt x \lt 1$ 時，$f'(x) \gt 0$（嚴格遞增）；當 $1 \lt x \lt 3$ 時，$f'(x) \lt 0$（嚴格遞減）。
故當 $x = 1$ 時，長方體的容積 $f(x)$ 會最大（最大容積為 $f(1) = 16$ 立方公寸）。
（註：兩軸刻度比例不同）
🔥 【學霸另解：算幾不等式配係數秒殺法】 欲求 $f(x) = x(6 - 2x)(6 - 2x)$ 在 $0 \lt x \lt 3$ 的最大值，為了使三個括號相加消去 $x$，將第一項乘以 $4$：
\[ 4f(x) = (4x)(6 - 2x)(6 - 2x) \le \left(\frac{4x + (6 - 2x) + (6 - 2x)}{3}\right)^3 = \left(\frac{12}{3}\right)^3 = 64 \implies f(x) \le 16 \] 等號成立於 $4x = 6 - 2x \implies 6x = 6 \implies x = 1$，3 秒直接驗算完畢！
答：(1) $0 \lt x \lt 3$  ｜  (2) $4x^3 - 24x^2 + 36x$  ｜  (3) $1$
第 2 題：定周長矩形繞一邊旋轉所得直圓柱之最大體積中叢 p. 2-34
2. 設矩形 $ABCD$ 的周長為 $12$，現在以一邊 $\overline{AB}$ 為軸，將此矩形旋轉一周得到一個直圓柱，求此直圓柱體積的最大值。
（兩軸單位長 1:1 精準比例）
📘 【正規詳解】
步驟一：設定變數與建立體積函數
因為矩形 $ABCD$ 的周長為 $12$，故鄰邊和 $\overline{BC} + \overline{AB} = 6$。
設底面旋轉半徑 $\overline{BC} = x$，則直圓柱的高 $\overline{AB} = 6 - x$，其中 $0 \lt x \lt 6$。
直圓柱體積函數 $V(x)$ 為：
\[ \color{#2563eb}{V(x) = \pi x^2 (6 - x) = \pi(6x^2 - x^3)} \] 步驟二：微分求極值
\[ V'(x) = \pi(12x - 3x^2) = \color{#2563eb}{3\pi x(4 - x)} \] 如右圖體積函數曲線所示：在 $0 \lt x \lt 6$ 範圍內，令 $V'(x) = 0$ 得 $x = 4$。
當 $0 \lt x \lt 4$ 時 $V'(x) \gt 0$（遞增）；當 $4 \lt x \lt 6$ 時 $V'(x) \lt 0$（遞減）。
故當 $x = 4$（高 $h = 2$）時，直圓柱有最大體積 $V(4) = \pi \cdot 4^2 \cdot (6 - 4) = 32\pi$。
（註：兩軸刻度比例不同）
🔥 【學霸另解：算幾不等式秒殺法】 將體積寫為 $V(x) = 4\pi \cdot \left(\d\frac{x}{2}\right)\left(\d\frac{x}{2}\right)(6 - x)$。因為三個因式和 $\d\frac{x}{2} + \d\frac{x}{2} + (6 - x) = 6$ 為定值：
\[ V(x) \le 4\pi \left(\frac{\frac{x}{2} + \frac{x}{2} + (6 - x)}{3}\right)^3 = 4\pi \cdot 2^3 = \color{#dc2626}{32\pi} \] 等號成立於 $\d\frac{x}{2} = 6 - x \implies x = 4$（即半徑 ： 高 $= 2 : 1$ 時體積最大）！
答：最大值 $32\pi$
第 3 題：兩拋物線所圍區域內接矩形 $ABCD$ 的最大面積中叢 p. 2-35
3. 如圖，在兩拋物線 $y = -x^2 + 6$ 與 $y = 2x^2 - 12$ 所圍成的區域中，作一內接矩形 $ABCD$，其一組對邊 $\overline{AB}$、$\overline{CD}$ 分別平行於 $x$ 軸，且兩頂點 $A$、$B$ 在 $y = -x^2 + 6$ 上，而另兩頂點 $C$、$D$ 在 $y = 2x^2 - 12$ 上。求矩形 $ABCD$ 的最大面積。
（註：兩軸刻度比例不同）
📘 【正規詳解】
步驟一：利用對稱性設定頂點坐標
先求兩拋物線交點：$-x^2 + 6 = 2x^2 - 12 \implies 3x^2 = 18 \implies x = \pm\sqrt{6}$。
因為兩拋物線皆對稱於 $y$ 軸，可設第一象限頂點 $A(x, -x^2 + 6)$，第四象限頂點 $D(x, 2x^2 - 12)$，其中 $0 \lt x \lt \sqrt{6}$。
• 矩形的寬：$\overline{AB} = \color{#2563eb}{2x}$
• 矩形的高：$\overline{AD} = (-x^2 + 6) - (2x^2 - 12) = \color{#2563eb}{18 - 3x^2}$
故矩形面積函數為：
\[ \color{#2563eb}{f(x) = 2x(18 - 3x^2) = -6x^3 + 36x} \] 步驟二：微分求面積最大值
\[ f'(x) = -18x^2 + 36 = -18(x^2 - 2) = \color{#2563eb}{-18(x + \sqrt{2})(x - \sqrt{2})} \] 如右圖面積函數曲線所示：在 $0 \lt x \lt \sqrt{6}$ 內，令 $f'(x) = 0$ 得 $x = \sqrt{2}$。
當 $0 \lt x \lt \sqrt{2}$ 時 $f'(x) \gt 0$（遞增）；當 $\sqrt{2} \lt x \lt \sqrt{6}$ 時 $f'(x) \lt 0$（遞減）。
將 $x = \sqrt{2}$ 代入得最大面積：
\[ f(\sqrt{2}) = 2\sqrt{2} \cdot \left(18 - 3(\sqrt{2})^2\right) = 2\sqrt{2} \cdot 12 = \color{#dc2626}{24\sqrt{2}} \]
（註：兩軸刻度比例不同）
🔥 【學霸另解：面積平方配算幾不等式】 將面積函數提公因式寫成 $f(x) = 2x \cdot 3(6 - x^2) = 6x(6 - x^2)$。兩邊平方以產生 $x^2$ 次方關係，並將 $x^2$ 配上係數 $2$：
\[ \left[f(x)\right]^2 = 36x^2(6 - x^2)^2 = 18 \cdot (2x^2)(6 - x^2)(6 - x^2) \le 18 \left(\frac{2x^2 + (6 - x^2) + (6 - x^2)}{3}\right)^3 = 18 \cdot 4^3 = 1152 \] 開根號得 $f(x) \le \sqrt{1152} = \sqrt{576 \times 2} = \color{#dc2626}{24\sqrt{2}}$（等號成立於 $2x^2 = 6 - x^2 \implies x = \sqrt{2}$）！
答：$24\sqrt{2}$
第 4 題：拋物線 $y=(x+1)^2$ 上與定點 $A(2,0)$ 距離最近的點與最短距離中叢 p. 2-35
4. 求拋物線 $y = (x + 1)^2$ 上與點 $A(2, 0)$ 距離最近的點坐標及最近的距離。
📘 【正規詳解】 步驟一：建立距離平方函數 $f(x)$
設拋物線上的動點坐標為 $P(x, (x + 1)^2)$，則點 $P$ 到定點 $A(2, 0)$ 的距離為：
\[ \overline{PA} = \sqrt{(x - 2)^2 + \left((x + 1)^2 - 0\right)^2} = \sqrt{(x - 2)^2 + (x + 1)^4} \] 為了方便微分，討論距離平方函數 $f(x) = \overline{PA}^2 = (x - 2)^2 + (x + 1)^4$。
步驟二：微分並因式分解求臨界點
\[ f'(x) = 2(x - 2) + 4(x + 1)^3 = 2\left[(x - 2) + 2(x^3 + 3x^2 + 3x + 1)\right] \] \[ = 2(2x^3 + 6x^2 + 7x) = \color{#2563eb}{2x(2x^2 + 6x + 7)} \] 因為二次因式 $2x^2 + 6x + 7 = 2\left(x + \d\frac{3}{2}\right)^2 + \d\frac{5}{2} \gt 0$ 恆正，故令 $f'(x) = 0$ 得唯一實根 $x = 0$。
當 $x \lt 0$ 時 $f'(x) \lt 0$；當 $x \gt 0$ 時 $f'(x) \gt 0$，故在 $x = 0$ 處有最小值：
• 距離最近的點坐標為 $P(0, (0+1)^2) = (0, 1)$。
• 最近的距離為 $\overline{PA} = \sqrt{f(0)} = \sqrt{(0 - 2)^2 + (0 + 1)^4} = \sqrt{4 + 1} = \sqrt{5}$。
（兩軸單位長 1:1 精準比例）
🔥 【學霸另解：幾何法線正交斜率法】 從曲線外一點 $A(2,0)$ 到拋物線 $y = (x+1)^2$ 距離最近時，連線 $\overline{PA}$ 必垂直於 $P$ 點的切線（即法線必過點 $A$，如右上圖紅線與綠虛線垂直）！
設最近點 $P(x, (x+1)^2)$，因為切線斜率 $y' = 2(x+1)$，故法線斜率為 $\d\frac{-1}{2(x+1)}$。由兩點斜率公式：
\[ \frac{(x + 1)^2 - 0}{x - 2} = \frac{-1}{2(x + 1)} \implies 2(x + 1)^3 = -(x - 2) \implies 2x^3 + 6x^2 + 7x = 0 \implies x(2x^2 + 6x + 7) = 0 \] 直接看出唯一實根 $x = 0$，完全不必展開四次方！故最近點為 $P(0, 1)$，最短距離 $\overline{PA} = \sqrt{5}$。
答：$(0, 1)$，$\sqrt{5}$
（二）生醫流體、機率與圓錐內接圓柱極值問題（中叢 p.2-35 ～ p.2-36 第 5 題 ～ 第 7 題）
第 5 題：氣管咳嗽排除異物速度最大值中叢 p. 2-35
5. 當異物進入人的氣管時，就會引起咳嗽，咳嗽的速度與異物的大小有關。假設某人的氣管直徑為 $20$ 毫米，若異物的直徑為 $r$ 毫米，則咳嗽排除異物所需的速度為 $V$（毫米/秒）可以表示成 $V(r) = k(20r^2 - r^3)$，$0 \le r \le 20$，其中 $k$ 為正數。試問當 $r$ 等於多少時，咳嗽排除異物的速度最大？
📘 【正規詳解】 將速度函數對 $r$ 求一階導數（其中常數 $k \gt 0$）：
\[ V'(r) = k(40r - 3r^2) = \color{#2563eb}{kr(40 - 3r)} \] 令 $V'(r) = 0$，得 $r = 0$ 或 $r = \d\frac{40}{3}$。
• 當 $0 \lt r \lt \d\frac{40}{3}$ 時，$V'(r) \gt 0$，$V(r)$ 嚴格遞增。
• 當 $\d\frac{40}{3} \lt r \lt 20$ 時，$V'(r) \lt 0$，$V(r)$ 嚴格遞減。
且端點值 $V(0) = V(20) = 0$，故當 $r = \d\frac{40}{3}$ 毫米時，咳嗽排除異物的速度最大。
（註：兩軸刻度比例不同）
🔥 【學霸另解：算幾不等式配係數秒殺法】 欲求 $V(r) = kr^2(20 - r)$ 的最大值，將第三項乘以 $2$ 使三個因式相加能消去 $r$：
\[ V(r) = \frac{k}{2} \cdot (r)(r)(40 - 2r) \le \frac{k}{2} \left(\frac{r + r + (40 - 2r)}{3}\right)^3 = \frac{k}{2} \left(\frac{40}{3}\right)^3 \] 等號成立於 $r = 40 - 2r \implies 3r = 40 \implies r = \d\frac{40}{3}$，瞬間得出最大速度發生的位置！
答：$\d\frac{40}{3}$
第 6 題：連續三日僅有一日降雨之機率函數 $Q(p)$ 與最大值中叢 p. 2-36
6. 有一地方，一日之間降雨之機率為 $p$，不降雨之機率為 $1 - p$。今連續三日只有一日降雨之機率設為 $Q(p)$：
(1) 求 $Q(p)$ 之函數。
(2) 試問當 $p$ 為多少時，$Q(p)$ 有最大值。
📘 【正規詳解】 (1) 求機率函數 $Q(p)$：
連續三日中恰有一日降雨，可能發生在第 1 日、第 2 日或第 3 日（共 $\binom{3}{1} = 3$ 種互斥情形），每次情形機率皆為 $p(1-p)^2$，且機率範圍滿足 $0 \le p \le 1$：
\[ \color{#2563eb}{Q(p) = 3p(1 - p)^2,\quad 0 \le p \le 1} \] (2) 求 $Q(p)$ 最大值發生之 $p$ 值：
將 $Q(p) = 3p(1 - 2p + p^2) = 3p^3 - 6p^2 + 3p$ 對 $p$ 微分：
\[ Q'(p) = 9p^2 - 12p + 3 = 3(3p^2 - 4p + 1) = \color{#2563eb}{3(3p - 1)(p - 1)} \] 令 $Q'(p) = 0$，得 $p = \d\frac{1}{3}$ 或 $p = 1$。
當 $0 \lt p \lt \d\frac{1}{3}$ 時 $Q'(p) \gt 0$（遞增）；當 $\d\frac{1}{3} \lt p \lt 1$ 時 $Q'(p) \lt 0$（遞減）。
故當 $p = \d\frac{1}{3}$ 時，$Q(p)$ 有最大值（最大機率為 $Q\left(\d\frac{1}{3}\right) = \d\frac{4}{9}$）。
（註：兩軸刻度比例不同）
🔥 【學霸另解：算幾不等式配係數秒殺法】 欲求 $Q(p) = 3p(1 - p)^2$ 在 $0 \le p \le 1$ 的最大值，將第一項 $p$ 乘以 $2$ 即可與兩個 $(1 - p)$ 相加消去 $p$：
\[ Q(p) = \frac{3}{2} \cdot (2p)(1 - p)(1 - p) \le \frac{3}{2} \left(\frac{2p + (1 - p) + (1 - p)}{3}\right)^3 = \frac{3}{2} \left(\frac{2}{3}\right)^3 = \frac{4}{9} \] 等號成立於 $2p = 1 - p \implies 3p = 1 \implies p = \d\frac{1}{3}$，完全不必展開微分！
答：(1) $Q(p) = 3p(1 - p)^2$，$0 \le p \le 1$  ｜  (2) $\d\frac{1}{3}$
第 7 題：直圓錐內接直圓柱之體積函數與最大體積中叢 p. 2-36
7. 設一直圓錐高為 $9$，底半徑為 $3$，有一直圓柱內接於此直圓錐，如圖所示，令直圓柱之底半徑為 $x$，若直圓柱之體積為 $f(x)$，試求：
(1) 函數 $f(x)$。
(2) 直圓柱之最大體積。
（兩軸單位長 1:1 精準比例）
📘 【正規詳解】
(1) 利用相似三角形比例求直圓柱的高 $h$ 與體積函數 $f(x)$：
設內接直圓柱的底半徑為 $x$（$0 \lt x \lt 3$），高為 $h$。觀察直圓錐的縱截面，上方小圓錐與整個大圓錐相似，高與底半徑成正比：
\[ \frac{9 - h}{9} = \frac{x}{3} \implies 9 - h = 3x \implies \color{#2563eb}{h = 9 - 3x} \] 因此直圓柱的體積函數 $f(x)$ 為：
\[ f(x) = \pi x^2 h = \pi x^2 (9 - 3x) = \color{#2563eb}{\pi(9x^2 - 3x^3)} \] (2) 求直圓柱之最大體積：
對 $f(x)$ 求一階導數：
\[ f'(x) = \pi(18x - 9x^2) = \color{#2563eb}{9\pi x(2 - x)} \] 如右圖體積函數曲線所示：在 $0 \lt x \lt 3$ 內，令 $f'(x) = 0$ 得 $x = 2$。
當 $0 \lt x \lt 2$ 時 $f'(x) \gt 0$（遞增）；當 $2 \lt x \lt 3$ 時 $f'(x) \lt 0$（遞減）。
故當 $x = 2$ 時，直圓柱有最大體積 $f(2) = \pi(9 \cdot 2^2 - 3 \cdot 2^3) = 12\pi$。
（註：兩軸刻度比例不同）
🔥 【學霸另解：算幾不等式配係數法 ＋ 圓錐內接圓柱黃金結論】 • 方法一（算幾不等式）：將 $f(x) = 3\pi x^2(3 - x)$ 的最後一項乘以 $2$ 使相加消去 $x$：
\[ f(x) = \frac{3\pi}{2} \cdot (x)(x)(6 - 2x) \le \frac{3\pi}{2} \left(\frac{x + x + (6 - 2x)}{3}\right)^3 = \frac{3\pi}{2} \cdot 2^3 = \color{#dc2626}{12\pi} \quad (\text{等號成立於 } x = 6 - 2x \implies x = 2) \] • 方法二（黃金比例結論）：任何直圓錐（底半徑 $R$、高 $H$）的內接直圓柱，當圓柱半徑 $x = \d\frac{2}{3}R = 2$、圓柱高 $h = \d\frac{1}{3}H = 3$ 時體積必最大，且最大體積恆為圓錐體積的 $\d\frac{4}{9}$ 倍！
答：(1) $f(x) = \pi(9x^2 - 3x^3)$  ｜  (2) $f(2) = 12\pi$
